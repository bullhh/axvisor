## 方案分析

### 核心优势

1. **每个size class自带一个初始节点**：启动时不需要从page allocator申请任何节点
2. **空闲链表只管理动态扩展节点**：大大简化管理逻辑
3. **统一索引**：不需要区分静态/动态，所有索引都是全局唯一的

### 数据结构设计

```rust
/// 全局节点池（简化版）
pub struct GlobalSlabNodePool {
    // 每个size class的初始节点（9个，固定分配）
    initial_nodes: [ListNode<SlabNode>; SizeClass::COUNT],
    
    // 动态扩展节点池（从page allocator分配）
    dynamic_pool: DynamicNodePool,
    
    // 空闲链表（只管理动态节点）
    free_head: Option<usize>,
    
    // 统计
    total_capacity: usize,
    used_count: usize,
}

/// 动态节点池
struct DynamicNodePool {
    base_addr: Option<usize>,      // 动态区的物理基址
    capacity: usize,                // 动态区容量（节点数）
    expand_size: usize,            // 每次扩展的节点数
}

const INITIAL_NODES: usize = SizeClass::COUNT;  // 9个初始节点
const DYN_EXPAND_SIZE: usize = 64;              // 每次扩展64个节点
```

### 索引规则

```rust
impl GlobalSlabNodePool {
    /// 索引范围：
    /// 0 ~ 8       : 初始节点（每个size class一个）
    /// 9 ~ MAX     : 动态扩展节点
    
    fn is_initial_node(&self, idx: usize) -> bool {
        idx < INITIAL_NODES
    }
    
    /// 获取节点基址
    fn node_base_addr(&self, idx: usize) -> usize {
        if self.is_initial_node(idx) {
            // 初始节点：返回initial_nodes[idx]的地址
            &self.initial_nodes[idx] as *const _ as usize
        } else {
            // 动态节点：返回dynamic_base_addr + offset
            let offset = (idx - INITIAL_NODES) * NODE_SIZE;
            self.dynamic_pool.base_addr.unwrap() + offset
        }
    }
    
    /// 获取节点引用
    fn get_node(&self, idx: usize) -> Option<&ListNode<SlabNode>> {
        if idx >= self.total_capacity {
            return None;
        }
        
        let addr = self.node_base_addr(idx);
        unsafe {
            Some(&*(addr as *const ListNode<SlabNode>))
        }
    }
    
    fn get_node_mut(&mut self, idx: usize) -> Option<&mut ListNode<SlabNode>> {
        if idx >= self.total_capacity {
            return None;
        }
        
        let addr = self.node_base_addr(idx);
        unsafe {
            Some(&mut *(addr as *mut ListNode<SlabNode>))
        }
    }
}
```

### SlabCache改造

每个SlabCache在创建时就包含一个初始节点：

```rust
// 在SlabCache中添加初始节点标识
pub struct SlabCache {
    size_class: SizeClass,
    pub(crate) empty: SlabPooledLinkedList,
    pub(crate) partial: SlabPooledLinkedList,
    pub(crate) full: SlabPooledLinkedList,
    initial_node_idx: usize,  // 该size class对应的初始节点索引
}

impl SlabCache {
    pub fn new(size_class: SizeClass, initial_node_idx: usize) -> Self {
        Self {
            size_class,
            empty: SlabPooledLinkedList::new(),
            partial: SlabPooledLinkedList::new(),
            full: SlabPooledLinkedList::new(),
            initial_node_idx,
        }
    }
    
    /// 初始化时将初始节点放入empty链表
    pub fn init_with_initial_node(&mut self, pool: &mut GlobalSlabNodePool, 
                                   node_addr: usize, page_allocator: &mut dyn PageAllocatorForSlab,
                                   page_size: usize) -> AllocResult<()> {
        // 分配初始节点的内存
        let object_size = self.size_class.size();
        let bytes_needed = 512 * object_size;
        let page_count = (bytes_needed + page_size - 1) / page_size;
        
        let start_addr = page_allocator.alloc_pages(page_count, page_size)?;
        let initial_node = SlabNode::new(start_addr, self.size_class);
        
        // 初始化初始节点
        if let Some(node) = pool.get_node_mut(self.initial_node_idx) {
            node.data = Some(initial_node);
            node.prev = None;
            node.next = None;
            
            // 放入empty链表
            self.empty.push_back(pool, self.initial_node_idx);
            
            Ok(())
        } else {
            Err(AllocError::NoMemory)
        }
    }
}
```

### 节点分配（动态扩展）

```rust
impl GlobalSlabNodePool {
    /// 分配动态节点（初始节点不通过此函数分配）
    pub fn alloc_dynamic_node(
        &mut self,
        data: SlabNode,
        page_allocator: &mut dyn PageAllocatorForSlab,
        page_size: usize,
    ) -> AllocResult<usize> {
        // 尝试从空闲链表获取
        if let Some(idx) = self.alloc_from_free_list(data) {
            return Ok(idx);
        }
        
        // 扩展动态区
        self.expand_dynamic_pool(page_allocator, page_size)?;
        
        // 再次尝试分配
        self.alloc_from_free_list(data)
            .ok_or(AllocError::NoMemory)
    }
    
    fn alloc_from_free_list(&mut self, data: SlabNode) -> Option<usize> {
        let idx = self.free_head?;
        
        // 读取next
        unsafe {
            let addr = self.node_base_addr(idx);
            let header = &*(addr as *const FreeNodeHeader);
            self.free_head = header.next;
        }
        
        // 设置节点数据
        if let Some(node) = self.get_node_mut(idx) {
            node.data = Some(data);
            node.prev = None;
            node.next = None;
        }
        
        self.used_count += 1;
        Some(idx)
    }
}
```

### 动态区扩展

```rust
impl GlobalSlabNodePool {
    fn expand_dynamic_pool(
        &mut self,
        page_allocator: &mut dyn PageAllocatorForSlab,
        page_size: usize,
    ) -> AllocResult<()> {
        const NODE_SIZE: usize = core::mem::size_of::<ListNode<SlabNode>>();
        
        // 计算需要的页数
        let bytes_needed = self.dynamic_pool.expand_size * NODE_SIZE;
        let page_count = (bytes_needed + page_size - 1) / page_size;
        
        // 分配内存
        let new_base_addr = page_allocator.alloc_pages(page_count, page_size)?;
        
        // 计算新节点的索引范围
        let start_idx = INITIAL_NODES + self.dynamic_pool.capacity;
        let end_idx = start_idx + self.dynamic_pool.expand_size;
        
        // 初始化新节点并链接到空闲链表
        for (i, idx) in (start_idx..end_idx).enumerate() {
            let offset = i * NODE_SIZE;
            let addr = new_base_addr + offset;
            
            unsafe {
                // 设置空闲链表指针
                let header = &mut *(addr as *mut FreeNodeHeader);
                if i < self.dynamic_pool.expand_size - 1 {
                    header.next = Some(idx + 1);
                } else {
                    header.next = None;
                }
                
                // 初始化SlabNode
                let node = &mut *((addr + core::mem::offset_of!(ListNode<SlabNode>, data))
                                   as *mut SlabNode);
                *node = SlabNode::new(0, SizeClass::Bytes8);
            }
        }
        
        // 将新块链接到空闲链表
        if let Some(tail) = self.find_free_list_tail() {
            unsafe {
                let addr = self.node_base_addr(tail);
                let header = &mut *(addr as *mut FreeNodeHeader);
                header.next = Some(start_idx);
            }
        } else {
            self.free_head = Some(start_idx);
        }
        
        // 更新动态池状态
        if self.dynamic_pool.base_addr.is_none() {
            self.dynamic_pool.base_addr = Some(new_base_addr);
        }
        self.dynamic_pool.capacity += self.dynamic_pool.expand_size;
        self.total_capacity = INITIAL_NODES + self.dynamic_pool.capacity;
        
        Ok(())
    }
}
```

### 节点释放

```rust
impl GlobalSlabNodePool {
    pub fn free_node(&mut self, idx: usize) {
        if idx >= self.total_capacity {
            return;
        }
        
        // 初始节点不释放到空闲链表，只清空数据
        if self.is_initial_node(idx) {
            if let Some(node) = self.get_node_mut(idx) {
                node.data = None;
            }
            return;
        }
        
        // 动态节点释放到空闲链表
        if let Some(node) = self.get_node_mut(idx) {
            if node.data.is_some() {
                node.data = None;
                
                unsafe {
                    let addr = self.node_base_addr(idx);
                    let header = &mut *(addr as *mut FreeNodeHeader);
                    header.next = self.free_head;
                    self.free_head = Some(idx);
                }
                
                self.used_count -= 1;
            }
        }
    }
}
```

### 完整内存布局

```
初始节点（BSS段，固定9个）
├── initial_nodes[0]   → Bytes8的初始节点  (索引0)
├── initial_nodes[1]   → Bytes16的初始节点 (索引1)
├── initial_nodes[2]   → Bytes32的初始节点 (索引2)
├── initial_nodes[3]   → Bytes64的初始节点 (索引3)
├── initial_nodes[4]   → Bytes128的初始节点 (索引4)
├── initial_nodes[5]   → Bytes256的初始节点 (索引5)
├── initial_nodes[6]   → Bytes512的初始节点 (索引6)
├── initial_nodes[7]   → Bytes1024的初始节点 (索引7)
└── initial_nodes[8]   → Bytes2048的初始节点 (索引8)

动态扩展区（从page allocator按需分配）
├── block 0 (扩展64个)
│   ├── node[9] ~ node[72]
├── block 1 (扩展64个)
│   ├── node[73] ~ node[136]
└── ...

每个SlabCache的初始状态：
├── empty:    [initial_node_idx]   (初始节点在empty链表)
├── partial:  []
└── full:     []

空闲链表（只管理动态节点）：
free_head → 9 → 10 → ... → 72 → 73 → ... (按需扩展)
```

### 方案优势总结

1. **极简初始状态**：
   - 9个初始节点（编译时分配）
   - 空闲链表为空（初始节点已在各自的cache中）
   - 零动态内存占用

2. **统一索引管理**：
   - 索引0-8：初始节点
   - 索引9+：动态节点
   - 无需复杂的枚举判断

3. **简化的释放逻辑**：
   - 初始节点：只清空数据，不回收到空闲链表（始终保持）
   - 动态节点：回收到空闲链表

4. **真正的按需扩展**：
   - 只有在需要更多slab节点时才扩展
   - 每次扩展固定数量（64个）
